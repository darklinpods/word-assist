# prompts/ 提示词口径说明

本目录是提示词资产的权威仓库，纳入 git 管理。改动提示词时以本说明为准，避免两套口径漂移。

## 目录内容

- `交通事故全案文书生成提示词_v2.md`：独立的全案文书生成提示词（湖北省/武汉市新洲区，2025 版）。适用于"证据资料 → 全套起诉文书"的对话式/agent 生成场景，**不参与 Word 插件的运行**。
- `湖北省赔偿标准_2025.json`：v2 提示词的配套赔偿标准数据（仅 v2 场景使用）。

## 插件运行使用的提示词

Word 插件（本仓库 `src/`）运行时不读取本目录。插件内嵌的提取提示词位于 `src/services/ai.ts`（`extractElementalComplaintFromText`），其契约是严格 JSON：缺失字段 = 空字符串、缺失角色 = 空数组，由 `src/services/ai-validators.ts` 强制校验。

## 两套提示词的关系

| 维度 | 插件提取提示词（`src/services/ai.ts`） | v2 全案生成提示词（本目录） |
|---|---|---|
| 用途 | 传统诉状 → 结构化要素 JSON | 证据资料 → 全套起诉文书 |
| 输出 | 严格 JSON，缺失 = 空字符串 | 自然语言文书，缺失 = 【占位符】 |
| 运行方 | Word 插件（火山方舟 API） | 对话式 agent |
| 共享原则 | 防幻觉：不编造事实、金额、日期、人名、车号等 | 同左（详见 v2 第一节） |

## 同步规则（重要）

1. 两套提示词共享的"防幻觉"原则如修改，需**同时**更新 `src/services/ai.ts` 与 v2 第一节。
2. 插件提取提示词**禁止**引入【】占位符规范或外部数据补全（如"保险公司主体信息.json"联动）：占位符或外部信息一旦进入提取 JSON，会被 `legacy-adapter.ts` 原样写入生成的 Word 文书，造成事实污染。这条禁令已在 `src/services/ai.ts` 防幻觉约束第 4、5 条中显式声明。
3. 新增提示词文件时在本说明登记用途；不再使用的提示词应删除而非留档，防止口径混淆。
