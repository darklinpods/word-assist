## 当前分支

`main`

## 当前状态

- 单一要素式起诉状生成流程：“读取诉状 → 查看要素 → 生成文书”。
- 提取结果只读展示，不提供文本框、添加、删除或修改入口。
- `DocumentDefinition<TDraft>` + 公共状态 Hook + 类型安全注册表。
- 交通事故要素式起诉状作为第一个文书模块。
- AI 输出为结构化当事人数据，并进行严格 JSON 校验。
- 法人车主与保险公司的互斥分类及代码级去重。
- 每次生成插入干净模板并单次回填，不覆盖已有文书。
- 证据核查作为不阻断生成的可选辅助区保留。
- 保留运行时 AI 配置引导。
- 已删除文本审查、索赔核定、金额修正、赔偿计算器等死代码。
- 新增 Vitest，覆盖核心纯函数。

## 最近的崩溃修复（2026-08-18）

- Mac 版 Word 16.112 通过 Office.js 枚举 `bookmarks.items` 时会原生闪退（崩溃日志显示 `Body.text` 成功取回正文后，在书签枚举处进程终止）。
- 提取路径（`getDocumentText`）与生成路径（`insertTemplateAndFill`）均移除书签枚举/写入，只保留 `body.text` 读取。
- 随之删除 `generated-region.ts`（书签排除与命名纯函数）及其单元测试。
- 取舍与约束见 ADR 0007。

## 关注点

- 模型提示词不能替代代码级角色规则。

- `localStorage` 中的 API Key 只适合个人受控设备，团队部署需要后端代理。
- 在确认目标 Word 版本不再崩溃前，避免重新引入 `bookmarks.items` 枚举。
