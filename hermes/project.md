# 项目定义

## 一句话说明

`word-assist` 是面向中国民事诉讼场景的 Microsoft Word 任务窗格插件，当前重点服务于交通事故人身损害赔偿案件。

## 用户与价值

- 主要用户：处理民事诉讼文书的律师及法律从业者。
- 核心价值：在 Word 内完成诉状审查、信息提取、赔偿核验、证据检查与模板回填，减少重复录入和人工核算。
- 人机边界：AI 结果是辅助材料，不构成正式法律意见；最终内容必须由专业人员复核。

## 核心能力

- AI 文本审查与建议回写。
- 赔偿项目提取、规则核验、计算和修正。
- 证据清单完整性检查。
- 当事人及诉状结构化信息提取。
- 要素式诉状模板插入与自动回填。
- 身份证号码校验与问题定位。

## 产品约束

- Office 写入能力只在 Word 宿主中可用，浏览器模式主要用于界面和非 Office 逻辑调试。
- 法律标准、赔偿参数和模型输出均具有时效性，不能被视为永久正确。
- 文档写入应尽量保留用户原文，并避免破坏模板表格结构和原文分页。
- API 凭证不得提交到版本库；生产环境宜通过后端代理调用模型。

## 成功标准

- 用户能稳定地从当前文档读取内容并获得结构化结果。
- 结构化结果能准确写入预期模板位置，且格式一致。
- 对旧版 Word 或缺失 API 能力有明确、可接受的降级行为。
- 金额和法律内容具有可复核路径，不以 AI 输出替代人工判断。
