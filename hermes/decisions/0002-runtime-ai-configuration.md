# ADR 0002：个人 AI 凭证采用运行时配置

- 状态：已接受
- 日期：2026-07-29

## 背景

原实现只从 Vite 构建时环境变量读取火山方舟 API Key 和推理接入点 ID。普通律师无法编辑 `.env.local`、运行构建并重新部署插件，因此分发后的产品无法自助启用 AI。

## 决策

- 未检测到配置时展示新手引导，说明火山方舟开通、API Key 和推理接入点的获取方法。
- 用户填写后先发起最小对话请求验证，成功才保存。
- 每位用户的配置保存在当前插件域名的 `localStorage` 中，并以版本化键名管理。
- 运行时配置优先于环境变量；环境变量仅服务 Vite 本地开发，生产构建不得携带开发者密钥。
- AI 请求发生时动态读取当前配置，避免设置更新后继续使用模块加载时的旧值。

## 影响

- 优点：非技术用户无需重新构建即可自助配置；错误能在正式使用前被发现。
- 代价：验证会产生极少量 Token 费用；浏览器本地存储不是高安全级别的密钥保险库。
- 约束：只建议用户在个人受控设备保存密钥。面向更大团队或不受信任设备部署时，应改为服务端代理、用户鉴权和服务端密钥管理。
