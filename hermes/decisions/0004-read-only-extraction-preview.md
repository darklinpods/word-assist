# ADR 0004：AI 提取结果采用只读预览

- 状态：已接受
- 日期：2026-08-12

## 背景

早期重构方案允许用户在生成前逐字段修改提取结果，但当前实际工作流只需要展示内容并直接生成。编辑控件增加了界面密度、状态复杂度，也会造成原始提取值、界面修改值和最终写入值之间的追踪困难。

## 决策

- 提取结果使用分区、可折叠的只读预览组件。
- 不提供 `input`、`textarea`、添加、删除或字段修改入口。
- 空字段显示“未提取到”，完整度和身份证问题继续单独提示。
- 如果结果不正确，用户修改原始文档后重新提取。
- 生成器直接使用当前展示的结构化结果，UI 不暴露 `setDraft`。

## 影响

- 优点：流程更短，展示内容和写入内容保持同源。
- 代价：轻微错误需要修改原文并重新调用 AI。
- 约束：以后若重新引入编辑能力，必须以新的 ADR 说明数据溯源、撤销和验证策略。
