# ADR 0001：Word 高级字体格式采用渐进增强

- 状态：已接受
- 日期：2026-07-26

## 背景

要素式诉状要求自动填入内容使用统一的字体、字号、字符宽度和字符间距。字体与字号是较基础的 Word API 能力，而 `font.scaling` 和 `font.spacing` 依赖 `WordApiDesktop 1.3`，旧版或非桌面宿主可能不支持。

如果所有属性在同一次同步中提交，高级属性失败可能连带导致核心文本写入流程报错。

## 决策

统一通过 `writeCellBody` 写入模板单元格，并分两阶段同步：

1. 清空单元格，写入文本，设置微软雅黑和 11 磅，然后同步。
2. 设置 85% 字符宽度和 0.25 磅字符间距，再次同步；仅此阶段允许因宿主不支持而降级。

## 影响

- 优点：旧宿主仍能完成文本和基础字体写入；所有回填路径格式一致。
- 代价：每个单元格增加同步次数，批量写入可能变慢。
- 约束：可选格式的异常处理范围必须保持最小，不能吞掉定位、数据或基础写入错误。
- 验证：构建检查之外，需要分别在支持和不支持高级字体属性的 Word 宿主中测试。
